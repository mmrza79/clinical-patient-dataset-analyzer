# Clinical Patient Dataset Analyzer

A Python-based clinical data analysis project for evaluating rehabilitation outcomes using patient assessment data.

## Overview

This project demonstrates a simple clinical analytics pipeline for rehabilitation datasets. It loads patient data, performs statistical analysis, and visualizes functional improvement after rehabilitation interventions.

## Features

- Load clinical patient data using Pandas
- Calculate demographic and clinical statistics
- Analyze BMI distribution
- Evaluate rehabilitation outcomes:
  - Berg Balance Scale (BBS)
  - Timed Up and Go (TUG)
- Generate visualization outputs

## Dataset

The sample dataset contains patient-level rehabilitation measurements including:

- Age
- Gender
- BMI
- BBS score before and after intervention
- TUG test results before and after intervention

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
